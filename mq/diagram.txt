|   Processo A     |                         |   Processo B     |

         |                                            ^

   |                POSIX Message Queue                     |
   |                    /robot_queue                        |
   |                                                        |
   |   +-----------------------------------------------+    |
   |   | Prioridade | Mensagem                         |    |
   |   +-----------------------------------------------+    |
   |   |    10      | "EMERGENCY_STOP"                 |    |
   |   |     5      | "SET_SPEED 100"                  |    |
   |   |     1      | "LOG_STATUS"                     |    |
   |   +-----------------------------------------------+    |
   |                                                        |
   |   mq_curmsgs = 3                                        |
   |   mq_maxmsg  = 10                                       |
   |   mq_msgsize = 256                                      |
   +--------------------------------------------------------+
         |
         | mq_receive()
         v
